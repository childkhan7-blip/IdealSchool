# Ideal Academy Vision

Create a clean, modern, and responsive website for a school named "Ideal Grammar School". Use a professional, trustworthy color palette (navy blue, warm white, and subtle golden accents) with clear typography and smooth transitions.

Structure the website with the following sections in order:

1. Navigation Bar:

   - School Logo / Name ("Ideal Grammar School")

   - Links to sections: Home, Principal's Message, Teachers, Schedule, About & Facilities, Contact & Location

   - "Apply / Contact Us" CTA button

2. Hero Section (Principal's Spotlight):

   - A prominent section at the very top.

   - Layout: Left side has a clean image container with placeholder avatar/image for the Principal. Right side displays Principal's Name ("Principal Name"), Title ("Principal's Welcome Message"), and a short, inspiring message highlighting academic excellence and discipline.

3. Teachers Section:

   - A grid layout displaying cards for faculty members.

   - Each card must include an image placeholder (Unsplash URL or avatar placeholder), Teacher's Name (e.g., "Mr. John Doe"), Subject/Designation (e.g., "Mathematics Lead"), and a short bio.

   - Code must be clean so image URLs and text fields can be easily replaced.

4. Daily Schedule & Period Timings Section:

   - Clearly highlight that each academic class period is strictly 45 minutes long.

   - Include a visual timetable or breakdown schedule:

     * Assembly / Homeroom: 15 mins

     * Periods 1 to 4: 45 minutes each

     * Section Break / Recess: 30 minutes (clearly styled as a section break)

     * Periods 5 to 7: 45 minutes each

5. Essential School Information & Facilities:

   - Grid or card section featuring core school pillars: Academic Excellence, Computer & Science Labs, Library, Sports & Extra-Curriculars.

6. Location & Contact Section:

   - School address, email, contact phone number, and opening hours.

   - Embedded Google Map placeholder or interactive map card.

   - Simple contact form (Name, Email, Message).

7. Footer:

   - Quick navigation links, social media handles, and copyright notice for Ideal Grammar School.

Ensure the design is fully mobile-responsive, clean, and accessible.

8. Website must be in 3d shape wise to look premium
